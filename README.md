# Government tax reform

Proposals and analysis for **fundamental tax reform**. Primary focus: **Canada**. Designed so other jurisdictions can swap the baseline without rewriting the principles.

This repository is independent analysis. It is not a bill, not advice, and not affiliated with any government.

## The proposal in one page

Replace the stacked levy (personal income tax, corporate income tax, payroll taxes, capital gains taxes, recurrent property taxes) with:

1. A **single broad consumption tax** (VAT), starting at **20%** and declining **linearly to 8% over ten years**.
2. **Differentiated rates**: zero/reduced on essentials (unprepared food, medicine, education, children’s clothing); higher on luxuries, tobacco, alcohol, and carbon-intensive goods.
3. A **land value tax** of 0.5–1% on unimproved values, aimed at empty urban lots and speculative non-farm holdings — not active farmland or modest primary residences.
4. An **income-tested dividend** sized to offset regressivity for the bottom 40–50% of households.
5. **Entrenchment**: independent fiscal board; referendum + supermajority to reintroduce eliminated taxes or break the rate path.
